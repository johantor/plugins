Claude Code plugin marketplace

Work in Claude Code like a team.

Two plugins, one marketplace. crew splits a feature into planned lanes behind one review gate. board shows every session on your machine, so you see which one needs you.

$ claude plugin marketplace add johantor/plugins
$ claude plugin install crew@johantor
$ claude plugin install board@johantor

Install one or both. Or run /plugin in Claude Code and open Discover.

See the plugins Catalog on GitHub
The plugins

Pick what you need.

Each plugin lives in its own repository, with its own site, releases and changelog.

crew.

An agent team for Optimizely work. A lead plans the work and delegates each step to specialists that know the CMS they work in.

  • Specialists per lane. Backend, frontend, tests, design, review and more.
  • Hooks, not promises. Guardrails in code keep each worker in its lane.
  • One review gate. Nothing ships until it says go. It pays down tech debt too.
$ claude plugin install crew@johantor
Meet crew Source
board.

A local kanban board of every Claude Code session: what needs you, what is running, and what you closed today.

  • Needs me first. Permission prompts and questions move to the front.
  • Back in with one click. Copy resume copies the command to reopen a session.
  • Local only. A Node server on 127.0.0.1. Nothing is sent anywhere.
$ claude plugin install board@johantor
Meet board Source

Better together.

Sessions that run a crew: agent get a Crew badge on the board, and each subagent shows on the card with its current tool.

Manage

Update and remove.

  • claude plugin marketplace update johantorRefresh the catalog.
  • claude plugin update crew@johantorUpdate a plugin. The same for board@johantor.
  • claude plugin uninstall crew@johantorRemove a plugin.

Added the marketplace from johantor/crew before? That source is gone. Run claude plugin marketplace remove johantor, then the commands above. Removing a marketplace uninstalls its plugins, so install them again.
